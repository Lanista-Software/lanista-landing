## Architecture

**Astro (static output) + Tailwind CSS 3**, Turkish-first. No UI framework runtime: components are `.astro`; interactive widgets use **Zag.js** state machines via `@zag-js/vanilla` (`src/scripts/{tabs,accordion,mobile-menu}.ts`). Do not reintroduce LUI, Vue or Nuxt modules.

### Routing & i18n
- Turkish at the root (`/`, `/works/…`, `/services/…`), English under `/en/…`. Old `/tr/*` URLs 301 to the root (`netlify.toml`).
- `trailingSlash: 'always'` — every link, canonical and sitemap URL ends with `/`. Build hrefs with `localePath()` from `src/lib/i18n.ts`.
- `src/pages/**` are thin wrappers; page bodies live in `src/views/*Page.astro` and take a `locale` prop.
- Product (`/urunler/…`) and legal (`/yasal/…`) pages are Turkish-only: pass `locales={['tr']}` to `BaseLayout` so no hreflang is emitted.
- UI chrome strings: `ui` in `src/lib/i18n.ts`. Content strings: Contentrain.

### Content System (Contentrain)
- Content lives in `.contentrain/` (models, content, meta). Edit only through the Contentrain MCP tools (see `.claude/rules/`); never hand-edit `.contentrain/` JSON, `meta/`, `client/` or `context.json`.
- `#contentrain` (generated by `contentrain generate` into `.contentrain/client/`, gitignored) is imported **only** from build-time code: `src/lib/content.ts`, `src/lib/og-pages.ts` and `.astro` frontmatter. Never from `src/scripts/*` (browser code).
- Forms: every site form posts to the Contentrain Studio public forms endpoint of the single `leads` model (`src/scripts/studio-forms.ts`). Env: `PUBLIC_CONTENTRAIN_PROJECT_ID`, optional `PUBLIC_CONTENTRAIN_STUDIO_URL`, `PUBLIC_TURNSTILE_SITE_KEY` (see `.env.example`).

### Key files
- `src/layouts/BaseLayout.astro` — head (canonical, hreflang, OG/Twitter, JSON-LD `@graph`), header, footer, skip link.
- `src/lib/seo.ts`, `src/lib/schema.ts` — URL helpers and Schema.org builders (Organization `@id` is referenced everywhere).
- `src/lib/company.ts` — seller identity (Lanista Yazılım San. ve Tic. Ltd. Şti.) for footer, legal pages, JSON-LD. Never mix with Contentrain A.Ş.
- `src/pages/og/[...path].png.ts` + `src/lib/og-{pages,render}.ts` — build-time 1200×630 share cards (satori + resvg). Register new pages in `og-pages.ts`.
- `src/styles/global.css` — component classes (`.btn-*`, `.tag-*`, `.field`, `.reveal`) on top of the Tailwind tokens in `tailwind.config.cjs`.

### Working docs
- `docs/CHECKLIST.md` — every request and its status; keep it current.
- `docs/odeme-altyapisi.md` — payments: the landing has no payment code; "Satın al" links to `plans.checkout_url` (each product backend handles contracts, iyzico payment and subscriptions). Read before any payment work.
- `docs/iyzico-gereksinimleri.md`, `docs/kararlar-arama-verisi.md`, `docs/illustration-style.md`.

### Accessibility rules (WCAG 2.2 AA)
- Text contrast ≥ 4.5:1: CTA red is `danger-600`, never `danger-500` with white text; tags use `primary-700` on `primary-50`.
- Never nest a button in a link; style the link with `.btn`.
- Icon fonts get `aria-hidden="true"`; icon-only controls get an `sr-only` label. External links announce "(yeni sekmede açılır)".
- Forms: visible labels, `aria-invalid` + `aria-describedby` errors, focused error summary, `role="status"` result.
- Motion respects `prefers-reduced-motion`; `.reveal` content is visible without JS.

### Integrations
- Google Analytics G-K7HYYT7SYM (`CookieConsent.astro`, loaded only after opt-in; GA4 property p252432555, reports: https://analytics.google.com/analytics/web/#/a182648914p252432555/reports/intelligenthome), events via `data-track` attributes (`src/scripts/analytics.ts`); event schema and panel setup in `docs/analytics.md`.
- Fonts: self-hosted `@fontsource` Inter + Space Grotesk (latin + latin-ext only).
- Icons: Remixicon SVGs inlined at build by `src/components/Icon.astro` (no icon font). Content may store `ri-*` names.
- Hosting: Netlify (`netlify.toml`, Node 22).
